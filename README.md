# Mandelbrot Fractal Generator

A parallel implementation of the **Mandelbrot fractal** written in **C** using **MPI (Message Passing Interface)**. The program generates a colored fractal image and saves it as a Portable Pixmap (`.ppm`) file.

The project demonstrates how to divide a computational task among multiple processes, calculate separate parts of an image in parallel, and combine the results into one complete image.

## Overview

The Mandelbrot set is a mathematical fractal generated by repeatedly applying an equation to points on the complex plane. The program calculates how quickly each point escapes a defined boundary. That iteration count is used to assign a color to the corresponding pixel.

Instead of calculating the whole image on one process, this project uses MPI to divide the image rows among multiple processes. Each process calculates its assigned rows, and the root process gathers the pixel data and saves the complete image.

## Features

- Implemented in C.
- Uses MPI for parallel processing.
- Accepts image width, image height, and maximum iteration count at runtime.
- Distributes image rows among MPI processes.
- Handles uneven row distribution when the height is not evenly divisible by the number of processes.
- Calculates Mandelbrot iteration counts for every pixel.
- Colors escaping points with a smooth sine-based palette and paints points that never escape black.
- Collects results with `MPI_Gatherv`.
- Saves the generated image as `mandelbrot.ppm`.

## How It Works

1. **Initialize MPI:** Each process starts and gets its rank and the total number of processes.
2. **Read input:** Process 0 asks the user for the image width, height, and maximum iteration count.
3. **Broadcast input:** `MPI_Bcast` shares the input values with all processes.
4. **Divide the work:** The image is divided into row ranges. Some processes receive one extra row if the height cannot be divided evenly.
5. **Calculate pixels:** Each process calculates the Mandelbrot iteration count and RGB color for its assigned pixels.
6. **Gather results:** `MPI_Gatherv` collects the pixel data from all processes into the complete image buffer on process 0.
7. **Write the image:** Process 0 writes the assembled pixels to `mandelbrot.ppm`.
8. **Clean up:** The program frees allocated memory and finalizes MPI.

## Work Distribution

The program divides **rows**, rather than columns, among processes.

For an image height of 10 and 3 MPI processes, the distribution is:

| Process rank | Number of rows |
|---:|---:|
| 0 | 4 |
| 1 | 3 |
| 2 | 3 |

The first `height % process_count` processes receive one extra row. This keeps the workload as balanced as possible.

Each process stores only its assigned pixels in a local buffer. The complete image buffer is allocated on process 0, which receives the results from all processes after the calculations finish.

## Coloring

Each pixel is mapped to a point `c` in the complex plane:

- Real axis: from `-2.0` to `1.0`
- Imaginary axis: from `-1.5` to `1.5`

The color depends on the number of iterations before the point escapes:

- **Points inside the set** (never escape within the iteration limit) are black.
- **Points outside the set** get a color from a sine-wave palette, where each of the red, green, and blue channels is shifted by a different phase:

```c
red   = (int)(127.5 * (1 + sin(0.5 * t)));
green = (int)(127.5 * (1 + sin(0.5 * t + 2.0)));
blue  = (int)(127.5 * (1 + sin(0.5 * t + 4.0)));
```

Here `t` is the iteration count. Changing the `0.5` factor makes the color bands narrower or wider.

## Requirements

You need:

- A C compiler.
- An MPI implementation, such as Open MPI or MPICH.
- A terminal in an environment with MPI installed.

### Ubuntu installation

```bash
sudo apt update
sudo apt install build-essential openmpi-bin libopenmpi-dev
```

## Build and Run

### 1. Clone the repository

```bash
git clone https://github.com/asmaa406-as/Mandelbrot.git
cd Mandelbrot
```

### 2. Compile

The source file is `mandelbrot.c`. The `-lm` flag links the math library, which is needed for `sin`:

```bash
mpicc mandelbrot.c -o mandelbrot -lm
```

### 3. Run with multiple processes

For example, run the program with four processes:

```bash
mpirun -np 4 ./mandelbrot
```

The program prompts you to enter the image dimensions and maximum iteration count.

> If you run on a machine with fewer cores than the number of processes, Open MPI may refuse to start. Add `--oversubscribe` to allow it:
>
> ```bash
> mpirun --oversubscribe -np 4 ./mandelbrot
> ```

## Example Run

```text
$ mpirun -np 4 ./mandelbrot
Enter image width: 1000
Enter image height: 1000
Enter maximum iterations: 500
Mandelbrot image generated as mandelbrot.ppm
```

This creates a 1000 × 1000 image named `mandelbrot.ppm` in the current folder. You can change the values to generate images with different sizes and levels of detail.

| Setting | Result |
|---|---|
| `800 600 100` | Fast preview |
| `1000 1000 500` | Balanced quality and speed |
| `2000 2000 1000` | High detail, slower to generate |

## Input Parameters

| Parameter | Description |
|---|---|
| Image width | Number of pixels horizontally. Must be at least 2. |
| Image height | Number of pixels vertically. Must be at least 2. |
| Maximum iterations | Maximum number of iterations used to test each point. Must be at least 1. |

Larger image dimensions require more pixel calculations. Increasing the maximum iteration count reveals more detail near the edge of the set but also increases computation time.

## Output

The program generates an image file named:

```text
mandelbrot.ppm
```

The image uses the ASCII PPM `P3` format.

### Open the image on Ubuntu/Linux

```bash
xdg-open mandelbrot.ppm
```

### Open the image on Windows

Many viewers do not support PPM files. Convert it to PNG with ImageMagick:

```bash
magick mandelbrot.ppm mandelbrot.png
```

Then open `mandelbrot.png` with your usual image viewer. ImageMagick must be installed for the conversion command to work.
